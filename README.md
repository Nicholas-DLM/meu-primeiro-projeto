# Calculadora elétrica

Uma calculadora simples para encontrar a corrente elétrica a partir da potência e da tensão.

## Como usar

1. Digite a potência em watts (W).
2. Digite a tensão em volts (V).
3. Informe o fator de potência, entre 0 e 1.
4. Clique em **Calcular corrente**.

Para carga monofásica em corrente alternada, a calculadora usa a fórmula **I = P / (V × FP)**, em que FP é o fator de potência. Com FP igual a 1, o cálculo equivale a **I = P / V**.

## Exemplo

Para 5000 W, 127 V e fator de potência 0,8, o resultado é 49,21 A.
